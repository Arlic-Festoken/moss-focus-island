# Moss 2.0 UI 与积累感设计

## 目标

Moss 2.0 要从“功能完整的番茄钟仪表盘”升级为一款安静、精致、具有长期陪伴感的原生 Mac 应用。视觉参考 Apple 的原生空间秩序、层级和动效克制，以及 Anthropic 产品的暖色纸感、编辑式排版和可信赖语气，但不复制任何品牌组件。

成功不以增加更多统计项衡量，而以用户是否能在三个时刻感到工作正在成为资产衡量：

1. 开始前：今天的一小段会继续已有积累，而不是从零开始。
2. 完成后：这段时间立即落入任务、总时长和里程碑中。
3. 回望时：数月投入形成可阅读的编年史、领域地形与证据。

## 体验原则

- **积累先于激励**：总投入、成长跨度和个人纪录是主角，XP 与等级降为辅助信息。
- **证据先于徽章**：成就必须附带日期、投入或次数，避免无重量的图标陈列。
- **延续而非归零**：今日为零时仍展示历史积累，并用“继续加入”引导下一段。
- **安静而有回应**：完成反馈使用清晰数字、柔和材质和短暂位移动效，不使用撒花、震屏或高饱和庆典。
- **原生而有个性**：保留 macOS 窗口、菜单、键盘与辅助功能语义，使用 Moss 自己的暖纸背景、苔色强调和编辑式标题。

## 视觉系统

- 统一 8 点间距节奏、12/16/20 三档连续圆角和克制的 1px 边界；卡片阴影只用于英雄层级，普通信息组使用边界和明度区分。
- 新增三类表面：`standard` 用于主要内容，`quiet` 用于辅助信息，`hero` 用于当前行动与年度印记。
- 主标题允许使用系统衬线设计形成编辑感；正文、控件和数字继续尊重用户字体设置。计时与统计数字保持等宽。
- 根视图统一应用主题 tint，移除系统蓝色选中态对 Moss 色彩的干扰；亮暗模式和现有六套主题继续工作。
- 页面使用统一标题组件：小型 eyebrow、编辑式标题、说明文字和可选尾部状态，减少每页各自拼装造成的层级漂移。

## 核心体验

### 今日：把下一段接到已有积累上

- 空闲英雄区显示“把今天的一小段，加入 X 小时里”，而不是把 `0m` 作为最大视觉元素。
- 主按钮直接开始最近任务，五分钟点火保持为次要操作；同时显示今日完成和全部积累。
- 进行中仍以计时为主，但补充当前任务累计值，让用户知道正在加深哪个领域。
- 任务列表、专注天气和今日轨迹保留，降低重复圆角容器密度，强化项目、任务和动作的对齐关系。

### 完成反馈：一段投入落地的收据

- 三击记录完成后展示 4.8 秒的“积累收据”：本段时长、任务累计、全部累计和完成段数。
- 若本段跨过成就阈值，收据显示新里程碑；否则显示下一里程碑进度。
- 收据是内存态，不写入数据库；应用退出或收据消失不会影响专注记录。
- 减少动态效果开启时取消移动和缩放，只保留透明度过渡。

### 成长志：把统计重组为个人作品

- 侧栏“成就岛”改名为“成长志”，首屏以全部累计的完整句子和年度印记建立重量。
- 以最近 12 个月的月度编年史展示节奏变化，并突出最佳月份、最高单日、最长连续等个人证据。
- 岛屿全景保留为领域地图，但视觉降噪；区域大小继续表示有效时长，点击仍进入独立成长档案。
- 徽章网格改为“成长证据”：已解锁项优先显示日期和事实；下一里程碑单独显示明确差距。
- 年度热力图、个人纪录和地标排行继续存在，但排在主叙事之后。

### 时间线与壳层

- 时间线保持现有筛选、日期范围和数据行为，替换为统一页面标题、表面和指标组件。
- 侧栏底部在空闲时展示最近七天投入及历史总量；活跃时继续展示计时状态。
- 工具栏、菜单栏、刘海岛、设置和数据格式不改变行为；主题、字体、窗口恢复与静默启动保持兼容。

## 数据与边界

- 不修改 `MossDatabase`、JSON/CSV 格式或现有持久化路径。
- `FocusAnalyticsSnapshot` 新增从现有 `FocusSession` 推导的年度值、最近十二个月、最近七天、下一里程碑和最新解锁信息。
- 新增纯值类型 `FocusCompletionReceipt`，由完成前后的分析快照生成，供 `AppStore` 发布给界面。
- 所有时间分组使用注入的 `Calendar` 与 `now`，确保跨年、空月份和测试固定日期的行为确定。

## 验收标准

1. 今日空闲页不再以 `0m` 为首要信息，并明确连接历史累计与下一任务。
2. 完成一段有效专注后，记录仍按原逻辑持久化，同时出现内容正确的积累收据。
3. 跨越阈值时收据能识别新解锁成就；未跨越时显示下一里程碑。
4. 成长志首屏在 900×620 与宽窗口下都保持清晰层级，并展示全部累计、年度印记、十二月编年史和领域地图。
5. 空数据、仅放弃记录、跨年记录和当前连续为零时文案与布局仍成立。
6. 六套主题、亮暗模式、字体档位、减少动态效果、键盘和 VoiceOver 语义保持可用。
7. 行为检查、UI 合同检查、类型检查、应用构建和真实应用视觉回归全部通过。
