# Moss 1.3.0

这一版把 Moss 从“主窗口 + 专注岛”扩展成了可以安静留在桌面的专注伴侣。

## 桌面专注小组件

- 固定在桌面层，不会压在普通应用窗口上方。
- 支持拖动并记住位置。
- 可直接选择任务、先做 5 分钟或开始标准专注。
- 专注中可暂停、继续、结束，休息结束后也能直接返回。
- 可从菜单栏或「设置 → 桌面小组件」随时显示、隐藏和重置。

## 专注岛与交互

- 收起与关闭分开，右键菜单可快速隐藏。
- 拖动、展开和颜色切换更加平滑。
- 关键按钮与筛选控件增加更清晰的悬停和按压反馈。

## 页面优化

- 整理今日页中部信息层级。
- 优化时间线筛选、日期选择器与月度波形悬停反馈。
- 提高年度专注图的色阶对比度。
- 新增成长主题、桌宠板块与自定义图片背景。

数据仍然只保存在本机，不需要迁移已有记录。
